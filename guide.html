模型使用示例（curl · OpenAI 兼容接入）

接入地址：https://api.nowcoding.cn/v1
认证方式：你的 API Key
模型列表：GET /v1/models
curl https://api.nowcoding.cn/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer 你的 API Key" \ -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"你好"}]}'

支持的接口（OpenAI 兼容）：

  • GET /v1/models模型列表（无需 Key · 通告各模型上下文）
  • POST /v1/chat/completions对话补全（支持流式）
  • GET /v1/usage查询额度与用量
  • POST /v1/embeddings向量嵌入（当前上游模型暂不支持，仅限本地 mock）
